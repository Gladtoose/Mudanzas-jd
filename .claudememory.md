# Contexto Proyecto: Landing Mudanzas

## Técnico
* **Stack:** HTML5, CSS3, JavaScript (Vanilla).
* **Prod Model:** `claude-3-5-haiku` (Chatbot final).

## Objetivos Core
* **Captura:** Formulario/Chat para datos de presupuesto.
* **Acción 1:** Enviar aviso inmediato al dueño (Lead/Notificación).
* **Acción 2:** Agenda en calendario mediante previa confirmación del dueño.

## Reglas de Desarrollo
* Mantener código modular, limpio y ligero.
* Priorizar optimización de tokens en prompts.
